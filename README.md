bienvenue sur heracles, avant de commencer a utilise ce github, veuillez installer les bibliothèques nécessaires au fonctiennement de celui-ci. 

Backend :

```bash
cd backend 
npm install
```

Frontend :

```bash
cd frontend
npm install
```

DE PLUS
aucun .env ne vous a etait fourni, veuillez donc le recréer vous meme en incluant :

une connexion MongoDB (NoSQL)
Port de communication
Code JWT
Code encryptage
Cle api email.
